# Chiloé Trabajos — Sitio de Servicios

Sitio multi-página para empresa de servicios en Chiloé. 18 páginas de servicios con SEO completo.

**Demo:** https://chiloe-trabajos.netlify.app

## Qué es

Sitio web comercial para una empresa de servicios generales (electricidad, jardinería, limpieza, seguridad). Cada servicio tiene su propia página con contenido optimizado para Google.

## Stack

- HTML5 semántico
- CSS3 responsive (mobile-first)
- JavaScript vanilla
- SEO: sitemap.xml, robots.txt, meta tags por página

## Estructura

```
├── index.html          # Inicio con hero y servicios destacados
├── servicios/          # 18 páginas individuales por servicio
│   ├── aire-acondicionado.html
│   ├── arboles-lena.html
│   ├── cableado-industrial.html
│   ├── camaras-seguridad.html
│   ├── corte-pasto.html
│   └── ... (13 más)
├── assets/             # Imágenes y posters
├── sitemap.xml
└── robots.txt
```

## Diseño

- Responsive: funciona en desktop, tablet y móvil
- Navegación clara entre servicios
- Formulario de contacto en cada página
- Imágenes optimizadas con WebP
